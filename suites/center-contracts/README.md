# 新增三中心评分合同 v1.0.0

适用于架构中心、人工智能中心、智能驾驶中心的本次33个新仓。中心是报告组，技术仅决定使用software或matlab条款。软件17叶/56分；模型12叶/36分。三中心内逐仓按绑定合同评分，组间不合并原始分数。原APP、FW、新能源MATLAB合同和352叶参考保持。

依据为用户给定真实扫描中的8种提示变体，提取后有3组实质维度。原文提取并不完整：若干tiers误收“执行流程”编号；架构实际描述三维，SOLID实际描述五原则。此处明确恢复逐维输出，不把一段提示计为一叶。

本版修正：SOLID沿用明确0..4语义，满分由矛盾的3修正为4；Android/native重复编译、API、升级条款合并到对应技术边界；Python和集成仓按实际构建/接口/依赖判定；没有适用继承关系不能自动SOLID满分。缺失的架构/重复率/集成测试档位按原检查目的给出可核对标准，不冒充逐字原文。

模型保留12维和0..3档，不混入旧新能源13维合同。构建独立性明确源码与受控组件接口的优先级，并填补无独立组件单体空档。设备/分支不再靠名字推断通用性，必须有真实差异和验证。模型coverage不能冒充C语句coverage，未测保留unknown，仓外测试不能算仓内测试。

CI分衡量可执行仓内配置。远端CI执行、主机编译、模型仿真、模拟器、物理设备分别报告，互不替代。旧公开仓及四个私有预留仓不适用这次修订。
